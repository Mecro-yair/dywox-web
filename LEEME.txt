WEB DE DYWOX  -  https://dywox.vercel.app
=========================================

Archivos:
  index.html        toda la página (diseño, textos y ajustes)
  api/canal.js      busca solas las listas públicas de tu canal de YouTube
  api/playlist.js   lee una lista suelta (queda de reserva)

TODO SE AGREGA SOLO
La web busca TODAS las listas de reproducción PÚBLICAS del canal @dywox-3
y muestra sus videos. Cada lista es un tema (botón de filtro).
  - Video nuevo: agrégalo a una lista pública -> aparece en la web.
  - Lista nueva: créala PÚBLICA en YouTube -> aparece como tema nuevo.
  - Para quitar un video: sácalo de la lista.
Vercel lo actualiza cada 10 minutos. Las listas privadas no se muestran.
(Al abrir index.html desde tu PC se ve una lista guardada de respaldo.)

AJUSTES (abre index.html y busca: EDITA AQUÍ EL CONTENIDO DE TU WEB)
  - EXCLUIR: listas públicas que NO quieres en la web. Ahora: "GAMES".
  - NOMBRES: cómo se ve el nombre de cada lista en la web, y el orden de
    los botones. Ejemplo: "INGENIERIA ECONOMICA": "Ingeniería".
    Una lista que no esté aquí se muestra con su nombre de YouTube.
  - SHORTS: listas que son de Shorts (se ven en una fila vertical).

CAMBIAR LOS COLORES
Abre index.html y busca:  COLORES DE LA WEB (EDITA AQUÍ)
Ahí hay dos cosas:
  --fondo   el color de la barra, la portada y "Suscríbete" (ahora negro)
  --acento  el color de botones, REC, filtros, etc. (ahora rojo)
Justo encima hay una lista de colores listos (Rojo, Morado, Azul,
Turquesa, Verde, Rosa, Naranja). Copia la línea del color que quieras y
reemplaza la línea que empieza con "--acento:". Guarda y súbelo a GitHub.
Si quieres el fondo de color en vez de negro, pon en --fondo el mismo
código que en --acento (por ejemplo --fondo:#e0245e;).

PUBLICAR CAMBIOS
Sube los archivos cambiados a tu repositorio de GitHub (Macro-yair/dywox-web)
con "Add file > Upload files". Vercel publica la versión nueva solo.
